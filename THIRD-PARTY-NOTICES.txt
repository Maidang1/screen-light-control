Screen Light v3

The combined hardware/software brightness mapping and per-display calibration
were developed with reference to MonitorControl's Display.swift,
OtherDisplay.swift and PrefKey.swift. Windows device access, verification,
settings storage, UI and animation scheduling are implemented in C# here.

ScreenTools reference

Per-screen hardware worker isolation, termination after device communication
failure, display-change debouncing, resume handling, CCD display configuration
and DDC capability checks were developed with
reference to ScreenTools. The implementation here uses C# and local named pipes;
no TypeScript runtime or ScreenTools package is included.

ScreenTools: https://github.com/yosong-github/ScreenTools
